# 新芽

一个不预置人设、靠聊天慢慢长出来的陪伴 App。

## 有什么

- 聊天：流式输出，出错能重发，断网先记着、联网自动补答
- 三块自生长档案：关于你 / 关于我 / 我们之间，每 20 条对话更新一次
- 人设可写可养：默认她自己长；点开锁能改，保存自动锁回去
- 记忆分层：当天摘要 → 日记 → 交接，跨天缺的自动补记
- 搜历史对话、语气润色、发图与认字、换头像与名字、导入导出、余额显示
