# 新芽

一个不预置人设、靠聊天慢慢长出来的陪伴 App。

## 有什么

- **聊天**：流式输出，出错能重发，断网先记着、联网自动补答
- **三块自生长档案**：关于你 / 关于我 / 我们之间，每 20 条对话她自己长一次
  - 「关于你」「我们之间」：她说过的、你确认过的，标 `user` 永不覆盖
  - 「关于我」：默认她自己长；点「解锁编辑」才能手改，保存自动锁回
- **空白起步**：第一次打开只要填名字、自称、语气（温柔/活泼/安静），其余靠聊
- **原文层**：每条消息按天存成文件（`日记本/年/月/日.txt`），只增不改
- **记忆分层**：原文 → 日记（带标签和重要度）→ 存档（每 5 篇日记提炼）→ 交接
- **文件存储**：记忆和原文都在 App 私有目录，不走 localStorage，不怕 5MB 上限
- 搜历史、语气润色、发图与认字、换头像与名字、导入导出、余额、账本
- **没有**：语音输入、朗读、日程、待办、倒计时
